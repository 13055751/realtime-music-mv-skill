# 场景编排方法（Staging）中文审阅版

> 设计方法论，不是强制清单。给你词汇与原则，不给你枷锁。每条规则都可以在讲清"为什么"后打破。

## 1. 舞台三层法

任何一帧看作三层，主动分配注意力：

```text
前景 ACTION     动作/主体变化（谁在动、谁在说话）
中景 SUBJECT    承载情绪的主体（歌词意象、角色、核心图形）
背景 ATMOSPHERE 氛围/环境（网格、星空、色调、噪声）
```

原则：一层动两层静（全屏都在动=全屏都没动）；背景是情绪不是信息；三层可节奏性换位（换位要有理由）；每帧最多一个视觉焦点。

## 2. 情绪弧

整首歌是一条情绪曲线，先画弧再排镜头：INITIAL → MID → PEAK → FINAL 四状态。情绪拐点（平静→紧张、爆发→余韵）是镜头语言切换点。长器乐间隙是让舞台喘气的机会，设计"呼吸"（衰减/留白/余韵）。弧线形状要能凭脚本读出来。

## 3. 节奏与呼吸

MV 不是每一秒同样密，节奏来自密度差：密（快切/高元素/强运动）vs 疏（长镜/低元素/负空间）。负空间是设计过的；能量上来前先静一帧（对比制造冲击）；长镜头要活着（微动/呼吸/粒子沉降）；避免匀速（三连快切后的长镜更有力）。

## 4. 运动语言

响应感→ease-out/spring（起始快）；自然感→ease-in-out/定制曲线；恒定感→linear；物理感→spring+bounce（携带动量才允许回弹）。

原则：不用 ease-in 开头（迟钝感）；自定义曲线比内置强；进入/退出走同一条路径（空间一致性）；一首歌统一运动家族；运动速度=情绪（慢而稳/快而脆/弹而活）。

## 5. 视觉焦点与留白

一帧=一个焦点+支持性元素+留白。焦点由亮度/对比/运动/大小之一建立。留白是设计资产不是空。歌词唱完即清（残留=TIMING 缺陷）。文字/关键图形不与背景撞。

## 6. 自由与约束的平衡

skill 只锁三条底线：①同步（时间关系成立）；②确定性（同时间戳同帧）；③有进有出（开启必关闭）。这三条之上你是导演：能说清"为什么更好"就可以打破任何规则。
