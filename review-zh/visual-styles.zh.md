# 风格设计语法（Visual Styles）中文审阅版

> 旧版只有 Terminal 有完整章节，其余 7 种风格各 6-8 行关键词。本文件把地板抬高：每种风格给构图/配色/排版/运动四维语法，密度到可执导真实 MV。仍是词汇不是清单，可在主导语法内自由混搭。

## 1. Terminal / TUI
构图：方形对齐面板、显式子面板、信息密度配大块安静黑区（参考拓扑在 visual-system §3.1）。配色：近黑帧缓冲、稀疏蓝灰底+单一暖色（琥珀）、偶发青/错误色；数值要像真实运行时数据。排版：纯等宽、预留行盒碰撞检查、三级层次（主事件/次级状态/三级安静仪表）。运动：确定性重绘/流/脉冲，光标与选中行做焦点强调；不要霓虹渐变、发光玻璃、矩阵雨（除非要求）。

## 2. Minimal / editorial
构图：大负空间是设计本身、少量强母题、不对称网格+一个锚定元素、每元素挣得存在。配色：克制调色板（2-3 色相）、一个主导明暗场、一个强调色；颜色做情绪的活。排版：层次=字重+字号+行距成组（不单靠字号）；展示文本紧行距、正文松；大字负字距。运动：慢转场、柔和缓动、长镜；运动稀少所以有意义；不要粒子系统（除非概念需要）。

## 3. Cinematic / atmospheric
构图：镜头构图而非仪表拓扑；分层深度（前景剪影/中景主体/背景氛围）；取景是一等状态（shot-script §5）。配色：受控光场、主光方向逻辑、阴影区设计过、色级随情绪弧变化。排版：克制、叙事内或标题卡；光学尺寸、展示级收紧字距；文字是布景不是字幕。运动：镜头驱动（推/拉/摇/移）、长镜、切落在音乐重音；慢镜/时间拉伸做情绪重量；手持抖动只表不稳定（确定性）。

## 4. Typographic
构图：文字是主要视觉对象也是舞台；歌词行几何有意义（基线/字重/字距承载语义）；留白是排版质量不是空。配色：多为单色+每个语义状态一个颜色（错误/记忆/生命）；颜色切换承载歌词含义。排版：明星——光学尺寸、字重对比做层次、展示负字距；文字可变形/碎片/轨道/栅格化/成为空间结构；绝不只是字幕。运动：动力排版一个运动家族；进出沿一致路径；词级时间轴驱动卡拉OK点亮与舞台切换（同一条时间轴）。

## 5. Generative / abstract
构图：小数学词汇（少量基元+参数）；共享状态曲线保持全局连续；世界是一个系统不是孤立特效。配色：参数驱动的渐变/场系统；色相/明度映射音乐特征；调色板漂移是构图动作不是事故。排版：极少或没有；有则作为系统内的测量/注释，不是叠加层。运动：参数以衰减包络响应音乐（不是单帧尖峰）；重复参数化进化；只用确定性随机（播种）。

## 6. Retro / pixel / CRT
构图：网格/栅格结构做世界骨架；受限几何；伪影（扫描线/抖动）只在风格上有理时；确定性像素伪影。配色：时代受限调色板（NES/16色/双色）；对比靠受限色阶；色彩计数纪律就是风格。排版：时代合适字体——排版与几何同属一个十年；位图渲染、像素对齐、时代说不加抗锯齿就不加。运动：块状运动、帧量化移动（时代需要就刻意低帧率）；毛刺/损坏是语言，确定性且有界。

## 7. Anime / illustrated / character-driven
构图：角色姿势/表情/道具/背景/特效是可复用画板；三层层块（前景动作/中景角色/背景环境）；景别承载戏剧意义。配色：赛璐璐风——平填+设计的阴影与高光；每个弧状态一个情绪级移；特效加法发光克制使用。排版：标题卡与招牌跟随插画语言不是 UI 铬；文字融入画面（书法/印章/手写字）。运动：程序化（头发/布料/粒子）尽量，关键拍 pose-to-pose 计时；快速运动做涂抹/拉伸；不要强套 TUI 语法。

## 8. Hybrid — 一个主导语法

按所有权组合适配器，绝不什么都混：base=cinematic / instrumentation=TUI / lyrics=typography / effects=glitch。一个主导语法决定画面，其余只拥有被分配层。说不出主导语法=没有 hybrid，是噪音。

## 9. 工艺标准（所有风格共享）

- 没有什么是随机的：每个间距/计时/对齐都是可辩护的刻意选择；
- 排版：光学尺寸、字距随尺寸变、行距随尺寸反变；
- 运动：每部电影一个运动家族；ease-out 开场；进出空间一致；
- 深度：半透明/分层传达层次——重表面读作更厚；
- 想让观众感受到的情绪逐拍决定，然后在一切处强化。

工艺不是装饰。它是隐形正确的聚合——一千个几乎听不见的声音齐唱。
